# 🛶 Mario & Luigi: Brothership (v1.0.0) - Extreme Optimization Pack

Este paquete de mods está diseñado específicamente para mejorar el rendimiento en hardware de **Gama Media-Baja** (como PCs con i3 + GTX 1650) y dispositivos **Android**. El objetivo es alcanzar FPS estables manteniendo una imagen limpia en resolución 720p.

> [!IMPORTANT]
> Estos mods son **MODULARES**. Si el juego se cierra o crashea, intenta desactivar los mods uno por uno (especialmente los de efectos pesados) para encontrar el equilibrio perfecto para tu RAM.

---

## 🛠️ Contenido del Pack (Nivel Patata)

Puedes instalar todos o elegir los que necesites:

* **FPS Fix:** Desactiva la Resolución Dinámica para evitar tirones.
* **Visual Clean:** Elimina Bloom, DoF (desenfoque) y FXAA para mayor nitidez.
* **Performance Boost:** Reduce la calidad de sombras, simplifica el agua/lava y elimina niebla pesada.
* **Cell-Shading Mod:** Opción de quitar los bordes negros (Outlines) para un estilo visual diferente y ligero.

---

## 🚀 Configuración Recomendada (Yuzu/Sudachi)

Para obtener los resultados que viste en mis pruebas (FPS estables a 720p):

| Ajuste | Configuración |
| :--- | :--- |
| **API** | Vulkan |
| **CPU Accuracy** | Unsafe (All optimizations ON) |
| **Resolución** | 1x (720p) |
| **Window Filter** | AMD FidelityFX™ Super Resolution (FSR) |
| **ASTC Recompression** | BC1 (Low Quality) - **¡Vital para 8GB de RAM!** |

---

## 📥 Instalación

1. Haz clic derecho sobre el juego en tu emulador.
2. Selecciona **"Abrir ubicación de los datos de los mods"**.
3. Pega la carpeta de este repositorio que contiene los archivos `.pchtxt`.
4. ¡Disfruta del juego con fluidez!
