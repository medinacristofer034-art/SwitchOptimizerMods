Switch Optimizer Mods (Extreme Optimization) ⭐
Ultimate performance mods for low-end PCs (i3 + GTX 1650 and similar).

This repository contains custom .pchtxt patches to improve FPS and stability in over 20 Switch titles when using emulators like Eden, Citron, and Yuzu.

🚀 Features:
20+ Games optimized (Zelda, Mario, Kirby, and more).

Steam Deck & Android support.

Battery saving for handheld devices.

🛠️ How to install:
Download the folder for your game.

Right-click the game in your emulator and select 'Open Mod Data Location'.

Paste the folder there.
