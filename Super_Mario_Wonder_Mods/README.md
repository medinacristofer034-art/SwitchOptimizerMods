# 🛡️ Scientific Sanctuary: Project #18 - Wonder Clarity Edition
**Target Game:** Super Mario Bros. Wonder

## 🚀 Overview
*Super Mario Bros. Wonder* is a masterpiece of animation, but its native post-processing can look "soft" on high-resolution monitors or emulators. **Project #19** focuses on removing the internal blur and stabilizing the frame-pacing to ensure those 60 FPS feel like butter, even on 4GB VRAM GPUs.

> "Precision platforming requires precision visuals. We clear the path for the Elephant Mario."

---

## 🛠️ Included Optimizations
This pack is designed to be lightweight and "invisible" to the performance overhead:

| Mod Name | Function | Hardware Benefit |
| :--- | :--- | :--- |
| **Disable FXAA** | Removes the "smudge" effect on character edges. | Pixel-Perfect Sharpness. |
| **Disable Motion Blur** | Keeps the background clear during fast runs. | Reduces Eye Strain. |
| **Particle Buffer Fix** | Optimizes how the GPU handles "Wonder Effects". | Prevents drops during crazy events. |
| **Disable Bloom** | Softens the glow to focus on the vibrant colors. | Lower GPU Temperature. |

---

## 📋 Installation
1. **Emulator:** Works on **Ryujinx** and **Yuzu**.
2. **Setup:** - Right-click the game in your emulator list.
   - Select `Open Mods Directory`.
   - Drop the `.pchtxt` files from this folder.
3. **Graphics Setting:** Set Accuracy to **"High"** for best results with these mods.

---

## ⚠️ Technical Note
This game is highly dependent on **Shader Cache**. If you experience "stuttering" during the first few minutes, it is the emulator building the cache. Our mods help once the cache is ready by keeping the GPU load stable at 60 FPS.
