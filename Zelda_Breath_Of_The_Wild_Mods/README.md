# 🛡️ Project #16: Zelda: Breath of the Wild (Optimization & Clarity)

Welcome to the **Scientific Sanctuary**'s definitive profile for *The Legend of Zelda: BotW* (v1.6.0). This project focuses on removing the "blurry" post-processing layer of the original game to reveal a sharp, high-performance experience on **GTX 1050/1650** and **i3/i5 CPUs**.

---

## 📊 Performance Target
* **Hardware:** Mid-Range (GTX 1650 / 8GB RAM / i3-10th Gen).
* **Resolution:** Native 720p/1080p (No Dynamic Scaling).
* **Frame Rate:** Rock-solid **30 FPS** (Frametime stability focus).

---

## 🛠️ Included Modules (Safe & Tested)

| Module | Description | Impact |
| :--- | :--- | :--- |
| **Shadows Lite** | Reduces shadow resolution for GPU relief. | **High FPS Gain** |
| **Physics Simplify** | Optimized Hair & Water physics for the CPU. | **Stutter Reduction** |
| **Zero-Blur Policy** | Disables FXAA and Depth of Field (DoF). | **Extreme Clarity** |
| **Atmosphere Fix** | Removes heavy Fog and Bloom effects. | **Visual Precision** |
| **Static Resolution** | Prevents the game from looking blurry during combat. | **Consistency** |

---

## 🚀 Installation (Citron / Yuzu / Ryujinx)

1. **Right-click** on *Zelda: BotW* in your emulator.
2. Select **"Open Mod Data Location"**.
3. Create a folder named `Sanctuary_Optimization_Pack`.
4. Inside that folder, create another one named `exefs`.
5. Paste the `main.pchtxt` file (available in this repo) inside the `exefs` folder.
6. **Restart** the emulator and enjoy Hyrule like never before!
