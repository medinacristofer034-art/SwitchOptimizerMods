## 📂 Estructura del Repositorio
Para evitar crasheos y conflictos de memoria, los códigos `.pchtxt` se han organizado de forma individual:

### 🌟 Visual Fixes (Ultra Clarity)
* **Disable_Bloom**: Elimina el resplandor excesivo para una imagen más limpia.
* **No_Depth_of_Field**: Quita el desenfoque de fondo (DoF), permitiendo ver todo el escenario con nitidez.
* **Disable_Fog**: Elimina la neblina para mejorar la visibilidad a larga distancia.

### ⚡ Performance & Stability
* **Stable_30FPS**: Bloqueo de frames para evitar el "stuttering" o tirones.
* **Simplify_Water**: Optimización de mallas acuáticas para ganar FPS en zonas de agua.
* **Resolution_Downscale_0.5x**: Ideal para usuarios con gráficos integrados (PC Patata).

## 🛠️ Guía de Instalación
1. Descarga el contenido de este repositorio.
2. En tu emulador de preferencia, haz clic derecho sobre el juego y selecciona **"Abrir carpeta de mods"**.
3. Pega las carpetas de los mods que desees utilizar (se recomienda no mezclar mods de resolución).
4. **IMPORTANTE**: Para evitar el cierre inesperado al cargar la partida, asegúrate de activar la configuración de **Gráficos: Eden** y limpiar la caché de shaders.
