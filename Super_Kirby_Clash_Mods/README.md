# Super Kirby Clash - Performance Optimization Mod

Este mod está diseñado para mejorar la estabilidad y el rendimiento en **Super Kirby Clash**, permitiendo una experiencia fluida de inicio a fin incluso en hardware de gama media o baja.

## 🚀 Características
* **Desactivación de Oclusión Ambiental (AO):** Elimina las sombras de contacto para reducir la carga en la GPU y ganar FPS estables.
* **Optimización de Claridad:** Mantiene una imagen limpia y nítida, ideal para jugar a 720p o resoluciones superiores sin sacrificar rendimiento.
* **Sin Tirones:** Ajustes enfocados en eliminar el stuttering durante los combates intensos contra jefes.

## 🛠️ Instalación
1. Haz clic derecho sobre **Super Kirby Clash** en tu emulador.
2. Selecciona **"Abrir ubicación de los datos de mod"**.
3. Copia la carpeta de este mod dentro de ese directorio.
4. Asegúrate de que el mod aparezca activado en las propiedades del juego.

## 📈 Rendimiento Esperado
* **Resolución:** Optimizado para 720p (nativo) con posibilidad de escalar según el hardware.
* **Estabilidad:** Gameplay fluido y jugable de principio a fin.
